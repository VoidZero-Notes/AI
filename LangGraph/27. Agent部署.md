## 环境搭建

### 创建容器网络

容器网络用于容器与容器之间进行通信。

```shell
docker network create local-net
```

### 启动 PostgresSQL 容器

创建并启动PostgreSQL容器。

```shell
docker run -d \
  --name pg16 \
  --network local-net \
  -e POSTGRES_USER=admin \
  -e POSTGRES_PASSWORD=123123 \
  -v pg_data:/var/lib/postgresql/data \
  -p 5432:5432 \
  postgres:16
```

### 启动 pgAdmin

```bash
docker run -d \
  --name pgadmin4 \
  --network local-net \
  -e PGADMIN_DEFAULT_EMAIL=admin@qq.com \
  -e PGADMIN_DEFAULT_PASSWORD=123123 \
  -v pgadmin_data:/var/lib/pgadmin \
  -p 5050:80 \
  dpage/pgadmin4
```

启动后，创建一个数据库`langgraph_db`

### 启动 Redis 容器

```shell
docker run -d \
  --name redis7 \
  --network local-net \
  -v redis_data:/data \
  -p 6379:6379 \
  redis:7-alpine redis-server --appendonly yes
```

### 配置环境变量

找到项目根目录下的`.env`，添加以下环境变量：

```env
DATABASE_URI=postgres://admin:123123@pg16:5432/langgraph_db
REDIS_URI=redis://redis7:6379/0
```

环境变量配置使用数据库`langgraph_db`，但是默认库 `langgraph_db` 不存在，需要进入pdAdmin新建如下图，或在 Query Tool 里连到 `postgres` / `admin` 后执行：

```sql
CREATE DATABASE langgraph_db OWNER admin;
```

## 构建 Agent 镜像

Makefile文件新增build命令

```makefile
export PYTHONUTF8 := 1

.PHONY: build

build:
	uv run langgraph build -t langgraph-python-agent:$(TAG)
```

```shell
make build TAG=0.1.0
```

## 启动 Agent Server 容器

```shell
docker run -d \
  --name langgraph-agent \
  --network local-net \
  --env-file .env \
  -p 8123:8000 \
  langgraph-python-agent:0.1.0
```

这条命令里，只有最后的镜像名必须和构建结果一致，其余参数是启动时自己指定的。

| 参数 | 含义 | 能不能随便改 |
|---|---|---|
| `-d` | 后台运行 | 否，去掉会占用当前终端 |
| `--name langgraph-agent` | 容器名，方便 `docker logs` / `docker stop` | 能。不写则 Docker 随机起名 |
| `--network local-net` | 加入前面创建的容器网络，才能用主机名 `pg16`、`redis7` | 否，必须和 Postgres / Redis 同一网络 |
| `--env-file .env` | 从**宿主机**读 `.env`，注入成容器环境变量 | 路径必须能找到文件 |
| `-p 8123:8000` | 本机 8123 映射到容器内 8000 | 左边端口可改，右边 8000 是镜像监听端口 |
| `langgraph-python-agent:0.1.0` | 要启动的**镜像** | 不能乱写，必须是已 build 出来的镜像 |

### 容器名 vs 镜像名

`--name langgraph-agent` **不是**从项目配置里读出来的，是启动时给容器起的别名。可以改成 `aa`：

```shell
docker run -d \
  --name aa \
  --network local-net \
  --env-file .env \
  -p 8123:8000 \
  langgraph-python-agent:0.1.0
```

改的只是 Docker 里这个容器的名字，应用代码不变。

最后的 `langgraph-python-agent:0.1.0` 才是镜像名，来源是 Makefile 的 `-t`：

```makefile
build:
  uv run langgraph build -t langgraph-python-agent:$(TAG)
```

`make build TAG=0.1.0` 打出 `langgraph-python-agent:0.1.0`，`docker run` 最后一段必须写成这个。写成不存在的 `bb:0.1.0` 会报镜像找不到。若想换镜像名，先 tag 再 run：

```shell
docker tag langgraph-python-agent:0.1.0 bb:0.1.0
docker run -d --name aa --network local-net --env-file .env -p 8123:8000 bb:0.1.0
```

同名容器已存在（哪怕是 `Exited`）时，先删再建：

```shell
docker rm langgraph-agent
```

### `--env-file` 不是打进镜像

`.dockerignore` 已排除 `.env`，构建镜像时**不会**把密钥打进去。

`--env-file .env` 发生在 **`docker run`（启动时）**：Docker 在宿主机读这个文件，把键值变成容器进程的环境变量。容器里的程序读的是环境变量（`DATABASE_URI`、`REDIS_URI`、API Key 等），不是磁盘上的 `.env` 文件。

因此：

- 改密钥 / 数据库地址：改 `.env` 后重新 `docker run`（或删掉旧容器再启动），**不用重新 build**
- 正式部署同样是运行时注入，不要把 `.env` 拷进镜像

| 场景 | 做法 |
|---|---|
| 本地 Docker | `--env-file .env` 或 `-e KEY=value` |
| Compose | `environment:` / `env_file:` |
| Kubernetes | Secret + `envFrom` |
| 云平台 | 控制台 / CI 配环境变量或密钥服务 |

`.env` 写成相对路径时，Docker 在**当前工作目录**找文件。在别的目录执行会报 `open .env: The system cannot find the file specified`。两种写法都可以：

```shell
cd F:\python\langGraph-project
docker run -d --name langgraph-agent --network local-net --env-file .env -p 8123:8000 langgraph-python-agent:0.1.0
docker run -d \
  --name langgraph-agent \
  --network local-net \
  --env-file F:\python\langGraph-project\.env \
  -p 8123:8000 \
  langgraph-python-agent:0.1.0
```

### 返回容器 ID 不等于启动成功

`docker run -d` 打印一串 ID 只表示容器已创建并尝试启动。要用状态和日志确认服务真的起来了：

```shell
docker ps -a --filter name=langgraph-agent
docker logs langgraph-agent
```

`STATUS` 必须是 `Up`。若是 `Exited`，看日志。常见失败：Postgres 里还没有 `langgraph_db`（`FATAL: database "langgraph_db" does not exist`）。在 pgAdmin 建好库后：

```shell
docker start langgraph-agent
docker logs -f langgraph-agent
```
