`Command` 把状态更新与路由决定合成一次返回，同时也是工具函数的合法返回值、`invoke` 的合法输入。第01章节点返回字典更新状态，第06章的边决定走向哪个节点——这两件事此前一直是分开写的，`Command` 把它们接到一起。本篇只讲前者：节点 / 工具返回时用到的 `update`、`goto`、`graph` 三个参数；`resume`（从中断恢复）留到下一篇，这里只给出定义。

文档：[Graph API：Command](https://docs.langchain.com/oss/python/langgraph/graph-api#command) · [Command 参考](https://reference.langchain.com/python/langgraph/types/Command)

```python
# 节点直接返回字典
def node(state: State):
  return {"foo": "bar"}

# 等效于
def node(state: State):
  return Command(update={"foo": "bar"})
```

## 位置

`Command` 可以用在三个地方：

- 节点返回
- 工具函数返回
- 图调用（`invoke` 的输入）

### 节点返回

```python
def node(state: State):
  return Command(...)
```

### 工具函数返回

`ToolRuntime` 是依赖注入参数，签名里声明后由框架按类型自动传入，不需要调用方传参：

```python
@tool
def search(
  query: str,
  runtime: ToolRuntime[ContextSchema, StateSchema],  # 依赖注入
) -> Command:
  return Command(...)
```

- `runtime.tool_call_id` → 当前这次 tool call 的 id
- `runtime.state` → 当前图状态
- `runtime.context` → 传入的 context（第12章 `Runtime`）

### 图调用

```python
graph.invoke(input=Command(...))
```

> `resume` 的用法下一篇再讲。

## 参数

`Command` 支持四个参数：

- `update`：更新图状态，等效于节点直接返回字典
- `goto`：指定下一个节点，等效于动态边（第06章的条件边）
- `graph`：在子图中使用，跳到父图的某个节点（第18章）
- `resume`：恢复中断，下一篇讲

```python
def node(state: State):
  return Command(
    update={...},    # 更新的状态
    goto="node_b",
    graph=Command.PARENT,
  )
```

## 使用方式

| 参数     | 节点返回 / 工具返回 | 图调用 |
| -------- | -------------------- | ------ |
| `update` | ✅                    | ❌      |
| `goto`   | ✅                    | ❌      |
| `graph`  | ✅（必须在子图中）    | ❌      |
| `resume` | ❌                    | ✅      |

## 注意事项

`goto` 是叠加关系，不会移除已声明的静态边：节点的静态边和动态边都会得到执行，两条路径可能同时触发下一步。
