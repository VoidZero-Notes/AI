第13–16章覆盖 Assistant / Thread / Run / Cron 这些业务接口。Agent Server 另外提供运维探测，以及把已部署的 Assistant 暴露给外部协议。本篇两块：System（健康检查、版本信息、指标、文档页）和 MCP（把 Assistant 当成 MCP 工具来连）。调用前须已按第05章启动本地服务，并按第13章安装 SDK。

`langgraph-sdk==0.4.2` **没有** `client.system` 子客户端，System 全部走 `client.http`。MCP 也不是 SDK 里的一套 CRUD，而是服务端的 `/mcp/` 入口，用任意支持 Streamable HTTP 的 MCP 客户端连接。第13章路径表里的 A2A（`POST /a2a/{assistant_id}`）本篇不展开。

文档：[Health check](https://docs.langchain.com/langsmith/agent-server-api/system/health-check) · [Server information](https://docs.langchain.com/langsmith/agent-server-api/system/server-information) · [System metrics](https://docs.langchain.com/langsmith/agent-server-api/system/system-metrics) · [MCP endpoint](https://docs.langchain.com/langsmith/server-mcp) · 本地 OpenAPI：`http://localhost:2024/docs#tag/System`

| 接口            | 含义                                      |
| --------------- | ----------------------------------------- |
| `GET /ok`       | 健康检查，可选探数据库                    |
| `GET /info`     | 服务器版本、功能开关、部署元数据          |
| `GET /metrics`  | Prometheus 或 JSON 指标                   |
| `GET /docs`     | Swagger / OpenAPI 页面（HTML）            |
| `POST /mcp/`    | MCP 请求                                  |
| `GET /mcp/`     | MCP 流式                                  |
| `DELETE /mcp/`  | 终止 MCP 会话                             |

## 创建客户端

System 没有独立子客户端，全部通过 `client.http`：

```python
from langgraph_sdk import get_client

client = get_client(url="http://localhost:2024")
client
```

## 健康检查

> GET /ok

返回 `{"ok": true}`。`check_db=1` 时同时检查数据库连通性：

```python
await client.http.get("/ok")
```

```python
await client.http.get("/ok", params={"check_db": 1})
```

服务器异常，或 `check_db=1` 且数据库连不上时返回 500，`client.http` 抛出 `ServerError`。适合部署脚本和负载均衡的探针。

## 服务器信息

> GET /info

```python
info = await client.http.get("/info")
info
```

| 字段                   | 含义                        |
| ---------------------- | --------------------------- |
| `version`              | LangGraph API 服务器版本    |
| `langgraph_py_version` | `langgraph` Python 库版本   |
| `flags`                | 已启用的功能开关            |
| `metadata`             | 部署元数据                  |

```python
print("服务器版本:", info["version"])
print("langgraph Python 版本:", info["langgraph_py_version"])
print("功能开关:", info["flags"])
print("部署元数据:", info["metadata"])
```

## 系统指标

> GET /metrics

`format` 两种：`prometheus`（默认，文本）和 `json`。

### JSON

`client.http.get` 按 JSON 解析响应体，JSON 格式可以直接用：

```python
metrics = await client.http.get("/metrics", params={"format": "json"})
metrics
```

内容包括队列统计、Worker 统计、HTTP 统计等，适合程序读取。

### Prometheus

默认 `Content-Type` 是 `text/plain`。`client.http.get` 会把响应体交给 `orjson.loads`，非 JSON 必然失败。凡是返回非 JSON 的接口（Prometheus 文本、`/docs` 的 HTML）都要改用底层 `httpx` 客户端 `client.http.client`：

```python
r = await client.http.client.get(
  "/metrics",
  params={"format": "prometheus"},
)
print("Content-Type:", r.headers["content-type"])
print(r.text[:1000])
```

## API 文档页

> GET /docs

返回交互式 OpenAPI 页面（HTML），同样不能走 `client.http.get`。浏览器打开 [http://127.0.0.1:2024/docs](http://127.0.0.1:2024/docs) 即可，与第13章截图的是同一份文档。

## MCP：把 Assistant 暴露为工具

Agent Server 把已部署的 Assistant 做成 MCP 服务，传输是 Streamable HTTP。MCP 客户端只需要连：

```text
http://127.0.0.1:2024/mcp/
```

当前实现**没有会话**：每次 `/mcp` 请求独立，不累积上一轮 MCP 会话状态。图这一侧若跑的是有状态 Run，仍按第14章的 Thread 持久化，与 MCP 传输层无会话不是一回事。鉴权与其余 LangGraph API 相同。

要关掉该入口，在 `langgraph.json` 里设 `"disable_mcp": true`。

用官方 Inspector 验证本地服务是否能被 MCP 客户端发现（需本机已装 Node.js）：

```bash
npx -y @modelcontextprotocol/inspector@1.0.0
```

Inspector 起来后，在界面里把 Transport 设为 Streamable HTTP，URL 填 `http://127.0.0.1:2024/mcp/`。连上后应能列出 Agent Server 暴露出的工具（每个 Assistant 一份）。本篇不编写 MCP 客户端代码。
