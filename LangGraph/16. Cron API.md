第15章的 Run 是当场发起的一次执行。Cron 按时间表反复创建 Run，类似操作系统的 cron。本篇用 `langgraph-sdk` 调用 Crons 接口：创建无状态 / 有状态定时任务，搜索、统计、启用禁用、修改与删除。调用前须已按第05章启动本地服务，并按第13章安装 SDK。

一次 Cron 触发就是第15章的一次 Run：无状态 Cron 每次新建线程，跑完默认删掉；有状态 Cron 绑死一条线程，每次往同一会话追加。本篇创建时一律 `enabled=False`，避免本地演示期间按计划反复打模型；需要观察 `next_run_date` 时再短暂启用。

文档：[Cron jobs](https://docs.langchain.com/langsmith/cron-jobs) · 本地 OpenAPI：`http://localhost:2024/docs#tag/crons`

| 概念           | 作用                                                                 |
| -------------- | -------------------------------------------------------------------- |
| Cron           | 按 cron 表达式周期创建 Run                                           |
| 无状态 Cron    | 每次执行新建线程。`on_run_completed`：`delete`（默认）/ `keep`       |
| 有状态 Cron    | `create_for_thread` 绑定固定 `thread_id`，上下文可跨次累积           |
| `cron_id`      | 创建后返回的 UUID                                                    |
| `schedule`     | 5 段 cron 表达式。不传 `timezone` 时按 **UTC** 解释                  |
| `enabled`      | 是否调度。`False` 时创建但不触发                                     |
| `next_run_date`| 下一次执行时间；禁用时无意义                                         |

## 创建客户端

```python
from langgraph_sdk import get_client

client = get_client(url="http://localhost:2024")
client
```

## 准备工作

无状态 Cron 只需要 Assistant；有状态 Cron 还需要一条线程：

```python
assistant_id = "agent"

thread = await client.threads.create(
  metadata={"__name__": "Cron API 测试"}
)
thread_id = thread["thread_id"]
```

## 创建无状态 Cron

> POST /runs/crons

每次触发都自动新建线程。`on_run_completed="delete"`（默认）跑完即删线程；`"keep"` 会留下线程，须自行清理：

```python
cron = await client.crons.create(
  assistant_id=assistant_id,
  schedule="*/2 * * * *",
  input={"messages": [{"role": "user", "content": "定时任务：汇报当前时间"}]},
  metadata={"lesson": "cron-stateless"},
  enabled=False,
)
cron_id = cron["cron_id"]
cron
```

`*/2 * * * *` 是标准 cron 表达式，5 段：

| 位置 | 字段 | 取值范围        | 示例        |
| ---- | ---- | --------------- | ----------- |
| 1    | 分钟 | 0–59            | `*/2` 每 2 分钟 |
| 2    | 小时 | 0–23            | `9` 早上 9 点   |
| 3    | 日   | 1–31            | `*` 每天        |
| 4    | 月   | 1–12            | `*` 每月        |
| 5    | 星期 | 0–6（0 为周日） | `0` 周日        |

常用：`0 9 * * *` 每天 09:00 UTC；`*/5 * * * *` 每 5 分钟；`0 0 * * 1` 每周一零点 UTC。

## 创建线程 Cron

> POST /threads/{thread_id}/runs/crons

`create_for_thread` 绑定固定线程。每次执行往**同一条**线程追加消息，可累积多轮上下文：

```python
thread_cron = await client.crons.create_for_thread(
  thread_id=thread_id,
  assistant_id=assistant_id,
  schedule="0 9 * * *",
  input={"messages": [{"role": "user", "content": "每日晨报"}]},
  metadata={"lesson": "cron-thread"},
  enabled=False,
)
thread_cron_id = thread_cron["cron_id"]
thread_cron
```

### cron 对象常用字段

| 字段            | 含义                                                         |
| --------------- | ------------------------------------------------------------ |
| `cron_id`       | 任务 ID                                                      |
| `thread_id`     | 绑定的线程。无状态 Cron 每次新建，该字段通常为空             |
| `assistant_id`  | 触发时使用的助手                                             |
| `schedule`      | cron 表达式                                                  |
| `payload`       | 每次创建 Run 时的参数（`input`、`config` 等）                |
| `next_run_date` | 下一次执行时间                                               |
| `end_time`      | 结束时间；空则无限期                                         |
| `enabled`       | 是否启用                                                     |
| `metadata`      | 创建时传入，供搜索                                           |

## 搜索 Cron

> POST /runs/crons/search

按 `assistant_id`、`thread_id`、`enabled`、`metadata` 精确过滤，支持分页与排序：

```python
crons = await client.crons.search(
  metadata={"lesson": "cron-stateless"},
)
crons
```

```python
all_crons = await client.crons.search(limit=10)
[(c["cron_id"], c["schedule"], c["enabled"], c["next_run_date"]) for c in all_crons]
```

> GET /runs/crons/{cron_id}

`langgraph-sdk==0.4.2` 的 `client.crons` 尚未封装该接口（只有 `search` / `count` / `create` / `update` / `delete`）。按 ID 读取须走底层 HTTP：

```python
cron_detail = await client.http.get(f"/runs/crons/{thread_cron_id}")
cron_detail
```

## 启用 / 禁用

> PATCH /runs/crons/{cron_id}

`update(enabled=...)` 开关调度。启用不改 `schedule`，只让 `next_run_date` 开始生效：

```python
cron = await client.crons.update(
  cron_id=cron_id,
  enabled=True,
)
cron["enabled"], cron["next_run_date"]
```

演示完立刻关掉，避免本地服务按计划触发：

```python
cron = await client.crons.update(
  cron_id=cron_id,
  enabled=False,
)
cron["enabled"]
```

> **说明：** 不用的 Cron 必须删掉或保持禁用。遗留的启用任务会持续创建 Run、消耗模型调用。

## 修改 Cron

> PATCH /runs/crons/{cron_id}

同一 `update` 也可改调度计划、输入、元数据：

```python
updated = await client.crons.update(
  cron_id=thread_cron_id,
  schedule="30 8 * * *",
  input={"messages": [{"role": "user", "content": "每日晨报（提前半小时）"}]},
)
updated["schedule"], updated["payload"]["input"]
```

## 删除 Cron

> DELETE /runs/crons/{cron_id}

只删本篇创建的两条，不要对 `search()` 的全量结果做循环删除。删除后再次按 ID 获取会抛出 `NotFoundError`：

```python
from langgraph_sdk.errors import NotFoundError

await client.crons.delete(cron_id)
await client.crons.delete(thread_cron_id)

try:
  await client.http.get(f"/runs/crons/{cron_id}")
except NotFoundError as e:
  print("已删除：", e)
```

有状态 Cron 删的是调度，不是那条线程。演示用完后删除测试线程：

```python
await client.threads.delete(thread_id)
```
