Cron 按时间表反复创建 Run，类似操作系统的 cron 任务。本篇用 `langgraph-sdk` 调用 Crons 接口：创建无状态 / 有状态定时任务，搜索、统计、启用禁用、修改与删除。第15章的 Run 是当场发起的一次执行；本篇的 Cron 只是把发起时机交给时间表，底层触发的仍是同一种 Run。调用前须已按第05章启动本地服务，并按第13章安装 SDK。

一次 Cron 触发就是第15章的一次 Run：无状态 Cron 每次新建线程，跑完默认删掉；有状态 Cron 绑死一条线程，每次往同一会话追加。本篇创建时一律 `enabled=False`，避免本地演示期间按计划反复打模型；需要观察 `next_run_date` 时再短暂启用。

文档：[Cron jobs](https://docs.langchain.com/langsmith/cron-jobs) · 本地 OpenAPI：`http://localhost:2024/docs#tag/crons`

| 概念            | 作用                                                           |
| --------------- | -------------------------------------------------------------- |
| Cron            | 按 cron 表达式周期创建 Run                                     |
| 无状态 Cron     | 每次执行新建线程。`on_run_completed`：`delete`（默认）/ `keep` |
| 有状态 Cron     | `create_for_thread` 绑定固定 `thread_id`，上下文可跨次累积     |
| `cron_id`       | 创建后返回的 UUID                                              |
| `schedule`      | 5 段 cron 表达式。不传 `timezone` 时按 **UTC** 解释            |
| `enabled`       | 是否调度。`False` 时创建但不触发                               |
| `next_run_date` | 下一次执行时间；禁用时无意义                                   |

Cron **不会**发邮件、webhook 或往控制台 print。所谓「汇报」就是对应 thread 的 `messages` 里多一轮对话。

## 准备工作

无状态 Cron 只需要 Assistant；有状态 Cron 还需要一条线程。`thread_id` 必须用本次 `create` 的返回值，**不要写死**旧 ID。Studio 读 `metadata.__name__` 当线程标题，**不要和已有线程重名**，否则下拉里分不清看哪条：

```python
assistant_id = "agent"

thread = await client.threads.create(
  metadata={"__name__": "线程绑定 Cron 演示"}
)
thread_id = thread["thread_id"]
```

## 创建无状态 Cron

> POST /runs/crons

每次触发都自动新建线程。`on_run_completed="delete"`（默认）跑完即删线程；`"keep"` 会留下线程，须自行清理：

```python
cron = await client.crons.create(
  assistant_id=assistant_id,
  schedule="*/2 * * * *",
  input={"messages": [{"role": "user", "content": "定时任务：汇报当前时间"}]},
  metadata={"lesson": "cron-stateless"},
  enabled=False,
)
cron_id = cron["cron_id"]
cron
```

`*/2 * * * *` 是标准 cron 表达式，5 段：

| 位置 | 字段 | 取值范围        | 示例            |
| ---- | ---- | --------------- | --------------- |
| 1    | 分钟 | 0–59            | `*/2` 每 2 分钟 |
| 2    | 小时 | 0–23            | `9` 早上 9 点   |
| 3    | 日   | 1–31            | `*` 每天        |
| 4    | 月   | 1–12            | `*` 每月        |
| 5    | 星期 | 0–6（0 为周日） | `0` 周日        |

常用：`0 9 * * *` 每天 09:00 UTC；`*/5 * * * *` 每 5 分钟；`0 0 * * 1` 每周一零点 UTC。本地最小粒度是 **1 分钟**：`* * * * *`。

> **本地不支持秒级。** 写成 6 段 `*/30 * * * * *`（想每 30 秒）会被当成 5 段 `*/30 * * * *`（每 30 分钟）。`next_run_date` 会对到下一个整半点，看起来像「任务死了」。

## 创建线程 Cron

> POST /threads/{thread_id}/runs/crons

`create_for_thread` 绑定固定线程。每次执行往**同一条**线程追加消息，可累积多轮上下文：

```python
thread_cron = await client.crons.create_for_thread(
  thread_id=thread_id,
  assistant_id=assistant_id,
  schedule="0 9 * * *",
  input={"messages": [{"role": "user", "content": "每日晨报"}]},
  metadata={"lesson": "cron-thread"},
  enabled=False,
)
thread_cron_id = thread_cron["cron_id"]
thread_cron
```

### 结果在哪看

Studio **Graph** 右侧「New Thread / Submit your input」是手动跑图的输入区，**不是** Cron 结果。

1. 左上角选对 Assistant（本篇是 `agent`，不是「假模型」等其它助手；选错则线程列表里根本没有这条）
2. 打开创建时 `__name__` 对应的那条 thread
3. 进 **Chat**（可选，不到chat只要切换了下拉也能在下面列表看到汇报，不过的刷新不是实时的推送）
4. Chat **不会自动刷新** Cron 写进去的消息，刷新页面或重新点开该 thread

也可以用 SDK：`await client.threads.get_state(thread_id)`，看 `values.messages`。

### cron 对象常用字段

| 字段            | 含义                                             |
| --------------- | ------------------------------------------------ |
| `cron_id`       | 任务 ID                                          |
| `thread_id`     | 绑定的线程。无状态 Cron 每次新建，该字段通常为空 |
| `assistant_id`  | 触发时使用的助手                                 |
| `schedule`      | cron 表达式                                      |
| `payload`       | 每次创建 Run 时的参数（`input`、`config` 等）    |
| `next_run_date` | 下一次执行时间                                   |
| `end_time`      | 结束时间；空则无限期                             |
| `enabled`       | 是否启用                                         |
| `metadata`      | 创建时传入，供搜索                               |

> **本地不要传 `end_time`。** inmem 调度器会拿字符串和 `datetime` 比较，抛 `TypeError`，**整条 cron_scheduler 停掉**，所有 Cron 都不触发。

## 启用 / 禁用

> PATCH /runs/crons/{cron_id}

`update(enabled=...)` 开关调度。启用不改 `schedule`，只让 `next_run_date` 开始生效：

```python
cron = await client.crons.update(
  cron_id=cron_id,
  enabled=True,
)
cron["enabled"], cron["next_run_date"]
```

演示完立刻关掉，避免本地服务按计划触发：

```python
cron = await client.crons.update(
  cron_id=cron_id,
  enabled=False,
)
cron["enabled"]
```

`create` / `create_for_thread` 每次都是**新建一条**，不会改旧的。notebook **不要 Run All**：会再插一条 enabled 任务。同一 `thread_id` 上多条 `enabled=True` 会在同一分钟连跑多次。

> **说明：** 不用的 Cron 必须删掉或保持禁用。遗留的启用任务会持续创建 Run、消耗模型调用。

## 修改 Cron

> PATCH /runs/crons/{cron_id}

同一 `update` 也可改调度计划、输入、元数据：

```python
updated = await client.crons.update(
  cron_id=thread_cron_id,
  schedule="30 8 * * *",
  input={"messages": [{"role": "user", "content": "每日晨报（提前半小时）"}]},
)
updated["schedule"], updated["payload"]["input"]
```

## 删除 Cron

> DELETE /runs/crons/{cron_id}

只删本篇创建的两条，不要对 `search()` 的全量结果做循环删除。删除后再次按 ID 获取会抛出 `NotFoundError`：

```python
from langgraph_sdk.errors import NotFoundError

await client.crons.delete(cron_id)
await client.crons.delete(thread_cron_id)

try:
  await client.http.get(f"/runs/crons/{cron_id}")
except NotFoundError as e:
  print("已删除：", e)
```

有状态 Cron 删的是调度，不是那条线程。演示用完后删除测试线程：

```python
await client.threads.delete(thread_id)
```

## 完整演示：线程 Cron 每分钟汇报当前时间

前提：make studio 已起来。按段从上到下自己跑，不要 Run All

```python
# %%
from langgraph_sdk import get_client

client = get_client(url="http://localhost:2024")
assistant_id = "agent"

# %%
thread = await client.threads.create(  # type: ignore
  metadata={"__name__": "线程绑定 Cron 演示"},
)
thread_id = thread["thread_id"]
thread

# %%
thread_cron = await client.crons.create_for_thread(  # type: ignore
  thread_id=thread_id,
  assistant_id=assistant_id,
  schedule="* * * * *",
  input={"messages": [{"role": "user", "content": "定时任务：汇报当前时间"}]},
  metadata={"__name__": "每分钟汇报当前时间"},
  enabled=False,
)
thread_cron_id = thread_cron["cron_id"]
thread_cron

# %%
crons = await client.crons.search(thread_id=thread_id)  # type: ignore
crons

# %%
thread_cron = await client.crons.update(thread_cron_id, enabled=True)  # type: ignore
thread_cron

# %%
# 启用后等约 1 分钟
# Studio：agent → 「线程绑定 Cron 演示」→ Chat（必要时刷新）
state = await client.threads.get_state(thread_id)  # type: ignore
state["values"]["messages"]

# %%
# 看完立刻停，再删调度
thread_cron = await client.crons.update(thread_cron_id, enabled=False)  # type: ignore
thread_cron

# %%
await client.crons.delete(thread_cron_id)  # type: ignore
```
