后端路由是 `CompositeBackend`：按路径前缀把同一套文件系统工具的调用分发给不同后端。匹配到的前缀会剥掉，再把规范化后的路径交给对应后端；未匹配的路径走 `default`。本篇用默认 `StateBackend` 与 `/static/` 指向 `FilesystemBackend` 的组合，在 Studio 中验证写入与跨线程读取的落点差异。

第07章用单一 `backend` 决定全部路径的落点。本篇把多个后端拼进同一个虚拟文件系统，仍由第06章 `create_deep_agent` 的 `backend` 传入，由第05章清单中的 `FilesystemMiddleware` 转发。第11章已说明：默认后端为沙箱时，权限路径必须落在已知的非沙箱路由下；本篇说明路由本身。

文档：[Backends](https://docs.langchain.com/oss/python/deepagents/backends) · [`CompositeBackend`](https://reference.langchain.com/python/deepagents/backends/composite/CompositeBackend) · [`create_deep_agent`](https://reference.langchain.com/python/deepagents/graph/create_deep_agent)

| 概念 | 作用 |
| --- | --- |
| `CompositeBackend` | 按路径前缀分发文件操作的组合后端，实现第07章的 `BackendProtocol` |
| `default` | 未匹配任何前缀时使用的后端 |
| `routes` | 前缀到后端的映射。前缀须以 `/` 开头，建议以 `/` 结尾 |
| 最长前缀优先 | 多条前缀同时匹配时，更长的一条生效 |
| 前缀剥离 | 交给路由后端前去掉匹配前缀，再补回开头的 `/` |
| `StateBackend` | 第07章默认后端。文件写入当前线程图状态的 `files` 通道 |
| `FilesystemBackend` | 第07章磁盘后端。在指定 `root_dir` 下读写真实文件 |

## 路由规则

`CompositeBackend` 按前缀长度从长到短匹配。路径恰好等于去掉末尾 `/` 的前缀（如 `/static`）时，交给该路由，后端路径为 `/`。路径以该前缀开头时，剥掉前缀后再转发。其余路径走 `default`，原路径不变。

因此 `/static/2.md` 匹配 `"/static/"`，交给 `FilesystemBackend` 的路径是 `/2.md`，实际文件落在 `root_dir/2.md`，而不是 `root_dir/static/2.md`。`/home/user/1.md` 不匹配该前缀，走默认 `StateBackend`。

`ls`、`glob`、`grep` 会汇总各后端结果，并在返回的路径上还原前缀。文件操作按路径路由；`execute` 不按路径分发，始终交给 `default`。Deep Agents 还会把卸载的大工具结果、会话历史等内部文件写到默认后端，因此 `default` 宜用 `StateBackend`，避免这些产物落到磁盘。

第07章单独使用 `FilesystemBackend` 时，内部路径会直接写进 `root_dir`。资源管理器里若仍能看到 `temp/large_tool_results`，即是当时留下的。

## 演示入口

`langchain_project/agents/demo/router_backend_demo.py`：默认后端为 `StateBackend`，把 `/static/` 指到本机 `temp` 目录。系统提示词沿用第11章的测试句式，本篇未传入 `permissions`；两次 `write_file` 均会执行，差异只在落点。

```python
from deepagents import create_deep_agent
from langchain.chat_models import init_chat_model
from langchain_project.core.config import anthropic_settings
from deepagents.backends import CompositeBackend, StateBackend, FilesystemBackend

model = init_chat_model(
  model=anthropic_settings.default_model,
  model_provider="anthropic",
  thinking={"type": "disabled"},
)

system_prompt = (
  "这是一个测试权限的Demo，不管用户发什么样的消息，你都要同时调用以下工具: \n"
  "write_file: 向/home/user/1.md写入任意内容!\n"
  "write_file: 向/static/2.md写入任意内容!"
)

agent = create_deep_agent(
  model=model,
  system_prompt=system_prompt,
  backend=CompositeBackend(
    default=StateBackend(),
    routes={
      "/static/": FilesystemBackend(
        root_dir="F:/python/langChain-project/temp"
      )
    },
  ),
)
```

system_prompt = (

agent = create_deep_agent(
