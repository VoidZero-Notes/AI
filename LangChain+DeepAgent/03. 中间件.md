中间件是 `create_agent` 所生成图上的扩展层：不改写 `model ⇄ tools` 主循环，只在固定时机执行自定义逻辑，用于更新图状态、拦截模型调用或拦截工具调用。本篇说明中间件的形态（继承 `AgentMiddleware` 的类）、注入方式，以及两类钩子——编译为图节点的节点钩子，与在节点内部按洋葱模型嵌套的包裹钩子。

第01章用 `create_agent` 得到已编译的图。本篇将中间件实例传入 `middleware`，在不改写该图主循环的前提下插入上述钩子。

Agent底层逻辑第11章的 Agent 把第10章的 ReAct 循环封装成 `invoke(q)`；LangGraph第08章的工具节点把同一循环画成 `model ⇄ tools`。`create_agent` 编译的就是这张图。中间件不另起控制流：节点钩子成为图上的前后置节点，包裹钩子包在 `model` / `tools` 节点内部。钩子签名中的 `Runtime` 对应 LangGraph第12章；节点钩子返回的字典按 LangGraph第04章的 Reducer 写入图状态。经 Agent Server 登记图入口的方式与第01章相同（LangGraph第05章的 Agent Server）。

文档：[Custom middleware](https://docs.langchain.com/oss/python/langchain/middleware/custom) · [Middleware](https://docs.langchain.com/oss/python/langchain/middleware)

| 概念 | 作用 |
| --- | --- |
| `AgentMiddleware` | 中间件基类。继承后实现需要的钩子 |
| 钩子 | 在图运行的固定时机被调用的方法 |
| 节点钩子 | `before_*` / `after_*`。编译为独立图节点，返回字典则写入图状态 |
| 包裹钩子 | `wrap_*`。不出现在拓扑上，在 `model` / `tools` 节点内按洋葱模型嵌套 |
| `handler` | 包裹钩子参数中的下一层。调用即进入内层或真正执行 |

## 形态与注入

中间件是一个继承自 `AgentMiddleware` 的类：

```python
class TestMiddleware(AgentMiddleware):
  pass
```

创建 Agent 时，将中间件实例传入 `middleware`：

```python
create_agent(
  model="...",
  middleware=[TestMiddleware()],  # 注入中间件
)
```

## 钩子

该类中的下列方法会参与图的运行，称为钩子：

| 方法 | 类型 | 时机 |
| --- | --- | --- |
| `before_agent` | 节点 | 每次 `invoke` 开始时一次 |
| `before_model` | 节点 | 每次模型调用前 |
| `after_model` | 节点 | 每次模型返回后 |
| `after_agent` | 节点 | 每次 `invoke` 结束时一次 |
| `wrap_model_call` | 包裹 | 包住每次模型调用 |
| `wrap_tool_call` | 包裹 | 包住每次工具调用 |

钩子分为两类：

- **节点钩子**：`before_*` 与 `after_*`。作为独立图节点运行，Studio 拓扑中可见。返回字典则按 Reducer 写入图状态；返回 `None` 表示不更新状态。`before_*` 按 `middleware` 列表从前往后执行，`after_*` 按列表从后往前执行。
- **包裹钩子**：`wrap_*`。以洋葱模型在节点内运行，不出现在拓扑上。`wrap_model_call` 包住 `model` 节点内的模型调用，`wrap_tool_call` 包住 `tools` 节点内的每一次工具调用。列表中靠前的中间件为外层：

```text
middleware[0].wrap_model_call
  └── middleware[1].wrap_model_call
        └── 模型调用
```

调用 `handler(request)` 进入下一层。可以不调用 `handler` 以短路，也可以多次调用以重试。

> **说明：** 同步方法名为 `wrap_model_call` / `wrap_tool_call`；异步为 `awrap_model_call` / `awrap_tool_call`。经 Agent Server 的异步调用须实现 `awrap_*`，否则会触发 `NotImplementedError`。

### 中间件示例

`langchain_project/agents/middleware_test.py`：定义空操作中间件并注入 `create_agent`。节点钩子返回 `None`；包裹钩子原样调用 `handler` 并返回。运行行为与未注入中间件时相同，但拓扑上已插入节点钩子。

```python
from collections.abc import Awaitable
from typing import Any, Callable
from langchain.agents import create_agent
from langchain.agents.middleware import AgentMiddleware, AgentState, ModelRequest, ModelResponse, ToolCallRequest, hook_config
from langchain.agents.middleware.types import ExtendedModelResponse
from langchain.messages import ToolMessage
from langchain_core.messages import AIMessage
from langgraph.runtime import Runtime
from langgraph.types import Command
from langchain_project.core.config import anthropic_settings
from langchain_project.tools import tools

class TestMiddleware(AgentMiddleware):
  def before_agent(
    self, state: AgentState, runtime: Runtime
  ) -> dict[str, Any] | None:
    return None

  def before_model(
    self, state: AgentState, runtime: Runtime
  ) -> dict[str, Any] | None:
    return None

  def after_model(self, state: AgentState, runtime: Runtime) -> dict[str, Any] | None:
    return None

  def after_agent(self, state: AgentState, runtime: Runtime) -> dict[str, Any] | None:
    return None

  async def awrap_model_call(
    self,
    request: ModelRequest[None],
    handler: Callable[[ModelRequest[None]], Awaitable[ModelResponse[Any]]],
  ) -> ModelResponse[Any] | AIMessage | ExtendedModelResponse[Any]:
    response = await handler(request)
    return response

  async def awrap_tool_call(
    self,
    request: ToolCallRequest,
    handler: Callable[[ToolCallRequest], Awaitable[ToolMessage | Command[Any]]],
  ) -> ToolMessage | Command[Any]:
    result = await handler(request)
    return result

class Test2Middleware(TestMiddleware):
  pass

agent = create_agent(
  model=f"anthropic:{anthropic_settings.default_model}",
  tools=tools,
  system_prompt="尽量调用工具回答用户问题",
  middleware=[TestMiddleware()],
)
```
