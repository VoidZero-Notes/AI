大模型只能处理输入得到输出，没有任何其他功能。需要完成文本输出之外的能力时，必须借助 `Tool Calling`。

在 Agent 应用中，常见需求包括：

- 读取或写入一个文件
- 执行一段命令
- 联网搜索一些资料

这些功能大模型都无法直接处理。模型不会真的去打开文件、跑命令；它只能根据你声明的工具，决定「该调哪个、参数是什么」，真正干活的是调用方。

| 步骤        | 谁做   | 做什么                                       |
| ----------- | ------ | -------------------------------------------- |
| 定义函数    | 调用方 | 用 Python 实现 `read_file` / `write_file` 等 |
| 声明 schema | 调用方 | 把名称、描述、参数结构随请求发给模型         |
| 决定调用    | 模型   | 返回 `tool_calls`，**不执行**                |
| 真正执行    | 调用方 | 按 `name` 找到函数，传入 `arguments`         |

## 定义工具函数

工具就是普通 Python 函数。模型看不到这段代码，只能看到后面声明的 schema。

```python
from pathlib import Path

def read_file(filepath: str) -> str:
  """读取文件内容并以字符串形式返回"""
  with open(filepath, "r", encoding="utf-8") as f:
    return f.read()

# 测试：读取当前文件的前 200 个字符
# content = read_file(str(Path(__file__).parent / "agent" / "prompt" / "system.j2"))
# print(content[:200])

def write_file(filepath: str, content: str) -> None:
  """将内容写入文件"""
  with open(filepath, "w", encoding="utf-8") as f:
    f.write(content)

# 测试：写入测试文件
# write_file("test_write.txt", "Hello, this is a test file.\n这是测试文件。")
# print(read_file("test_write.txt"))
```

> **说明：** `write_file` 是覆盖写，不是追加。schema 里会把这一点写进 `content` 的描述，避免模型误以为是往文件末尾加内容。

## 绑定工具到上下文

发给模型的不是 Python 函数对象，而是一份 JSON schema。请求体里的 `tools` 字段定义「有哪些函数可调」；协议见 [DeepSeek Chat Completions](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/)，与 OpenAI 兼容接口同一套形状。

目前只支持 `type: function`，最多 128 个。字段要点：

| 字段                    | 作用                                                   |
| ----------------------- | ------------------------------------------------------ |
| `type`                  | 固定为 `function`                                      |
| `function.name`         | 工具名，通常与 Python 函数名一致，模型输出里会原样带回 |
| `function.description`  | 自然语言说明何时、如何用这个函数；模型靠它决定调不调   |
| `parameters`            | 入参的 JSON Schema；根类型固定为 `object`              |
| `parameters.properties` | 每个参数的类型和描述                                   |
| `parameters.required`   | 必填参数名列表                                         |

`name` 和 `description` 会直接影响模型是否调用、参数怎么填，不要写空、不要写与真实函数不符的描述。

### 会话 `session.py`

相对 07：会话里多挂一份 `tools`，请求时和 `messages` 一起带上。`print` 方便查看当前绑定了哪些工具。

| 相对 07                     | 现在                                                       | 原因                                              |
| --------------------------- | ---------------------------------------------------------- | ------------------------------------------------- |
| 只有 `id` / `messages`      | 增加 `tools`                                               | `chat.completions.create` 的 `tools` 参数从这里取 |
| 无 `__str__`                | `__str__` / `print` 把 `id`、`messages`、`tools` 打成 JSON | 绑定后先看上下文对不对                            |
| `save` 写 `id` + `messages` | 仍只写这两项                                               | `tools` 是当次请求参数，不进历史消息              |

```python
import json
import uuid
from pathlib import Path

class Session:
  def __init__(self, tools=[]):
    self.id = str(uuid.uuid4())
    self.messages: list[dict] = []
    self.tools = tools

  def add_message(self, message: dict):
    self.messages.append(message)

  def __str__(self) -> str:
    data = {"id": self.id, "messages": self.messages, "tools": self.tools}
    return json.dumps(data, ensure_ascii=False, indent=2)

  def print(self):
    print(self)

  def save(self):
    sessions_dir = Path(__file__).parent / "sessions"
    sessions_dir.mkdir(parents=True, exist_ok=True)

    data = {
      "id": self.id,
      "messages": self.messages,
    }

    path = sessions_dir / f"{self.id}.json"
    with open(path, "w", encoding="utf-8") as f:
      json.dump(data, f, ensure_ascii=False, indent=2)

  @classmethod
  def load(cls, session_id: str):
    path = Path(__file__).parent / "sessions" / f"{session_id}.json"
    with open(path, encoding="utf-8") as f:
      data = json.load(f)

    session = cls()
    session.id = data["id"]
    session.messages = data["messages"]
    return session
```

> **说明：** `save` / `load` 不读写 `tools`。落盘后再 `load`，需要重新挂上 schema，否则下一轮请求没有工具。

`create(..., tools=session.tools)` 之后，厂商通常把工具说明拼到系统上下文末尾，模型才能「看见」有哪些函数。形状类似：

```text

系统提示词
```

### 事件 `events.py`

流式输出除思考、正文外，还可能吐出 `tool_calls` 增量。相对前几篇，补三类事件，后面的 `printer` / `ToolCallsBuilder` 都靠它们。

```python
from collections import defaultdict
from collections.abc import Callable
from dataclasses import dataclass, field
from typing import Any

class Event:
  REASONING_START = "reasoning_start"
  REASONING = "reasoning"
  REASONING_END = "reasoning_end"
  CONTENT_START = "content_start"
  CONTENT = "content"
  CONTENT_END = "content_end"
  TOOL_CALL_START = "tool_call_start"
  TOOL_CALL = "tool_call"
  TOOL_CALL_END = "tool_call_end"
  COMPLETE = "complete"

@dataclass
class EventEmitter:
  _listeners: dict[str, list[Callable[..., Any]]] = field(
    default_factory=lambda: defaultdict(list)
  )

  def on(self, event: str, callback: Callable[..., Any]) -> None:
    self._listeners[event].append(callback)

  def emit(self, event: str, **data: Any) -> None:
    for cb in self._listeners.get(event, []):
      cb(event, **data)
```

### 打印 `printer.py`

监听新增的工具事件：开始时打「工具调用：」，结束时把拼好的 `tool_calls` 打成 JSON。

```python
import json
import sys
from agent.events import Event
from agent.model import Model

class ModelPrinterListener:
  def __init__(self, model: Model) -> None:
    self.model = model
    self.listening = True
    events = [v for k, v in Event.__dict__.items() if not k.startswith("__")]
    for e in events:
      model.on(event=e, callback=self._model_print_callback)

  def _model_print_callback(self, e: str, **args):
    if not self.listening:
      return
    if e == Event.REASONING_START:
      print("思考：")
    elif e == Event.REASONING_END:
      print()
    elif e == Event.CONTENT_START:
      print()
      print("内容：")
    elif e == Event.TOOL_CALL_START:
      print()
      print("工具调用：")
    elif e == Event.TOOL_CALL_END:
      print(json.dumps(args["value"], indent=2, ensure_ascii=False))
    elif e == Event.REASONING:
      print(f"\033[36m{args["chunk_value"]}\033[0m", end="")
    elif e == "content":
      print(f"\033[32m{args["chunk_value"]}\033[0m", end="")
    sys.stdout.flush()
```

### 模型 `model.py`

相对 07 的改动集中在「把 tools 传给接口」和「把流式 `tool_calls` 拼回去」。

| 相对 07                          | 现在                               | 原因                                                       |
| -------------------------------- | ---------------------------------- | ---------------------------------------------------------- |
| `create` 只带 `messages`         | 增加 `tools=session.tools`         | 模型才能看到可调用函数                                     |
| 流式只有思考 / 正文 Builder      | 增加 `ToolCallsBuilder`            | `tool_calls` 按 index 分片到达，要合并 id、name、arguments |
| 回写 `role` + `content` + 思维链 | 若有 `tool_calls` 一并写入 message | 下一轮历史里必须带着这次工具调用                           |

`tool_calls` 不能当字符串直接 `+=`。流式里同一条调用会拆成多块：先来 `id` / `name`，`arguments` 再一段段拼成完整 JSON 字符串。`ToolCallsBuilder.append_value` 按 `index` 对齐到列表里对应项。

```python
from abc import ABC, abstractmethod
from collections.abc import Iterator
from dataclasses import dataclass, field
import json
from typing import Any, cast
from agent.events import EventEmitter, Event
from agent.config import openai_settings
from agent.session import Session
from openai import OpenAI, Stream
from openai.types.chat import ChatCompletion, ChatCompletionChunk

def _get_reasoning_field_name(res_or_chunk):
  "为了兼容性，获取推理字段的名称"
  for attr_name in ["reasoning_content", "reasoning"]:
    if hasattr(res_or_chunk, attr_name):
      return attr_name
  return ""

@dataclass
class InvokeResult:
  message: dict
  raw: Any

  def print_raw(self):
    if isinstance(self.raw, ChatCompletion):
      print(self.raw.to_json(indent=2))
    else:
      data = [c.model_dump() for c in self.raw]
      print(json.dumps(data, ensure_ascii=False, indent=2))

class Builder(ABC):
  def __init__(self, emitter: EventEmitter):
    self.emitter = emitter
    self.value = None
    self.compoleted = False

  @abstractmethod
  def _key_names(self, delta) -> list[str]:
    "获取关键名称"
    pass

  def emit(self, chunk: ChatCompletionChunk):
    if self.compoleted:
      return
    if not chunk.choices:
      return
    delta = chunk.choices[0].delta
    field_name, start_event_name, event_name, end_event_name = self._key_names(
      delta
    )
    value = getattr(delta, field_name, None)
    if value:
      if not self.value:
        self.value = {field_name: value}
        self.emitter.emit(start_event_name)
      else:
        self.append_value(value, field_name)
      self.emitter.emit(event_name, chunk_value=value, chunk=chunk)
    if self.is_end(chunk):
      if self.value:
        self.emitter.emit(end_event_name, value=self.value, chunk=chunk)
        self.compoleted = True

  def append_value(self, value, field_name: str):
    self.value[field_name] += value  # type: ignore

  def is_end(self, chunk: ChatCompletionChunk):
    return bool(chunk.choices[0].finish_reason)

class ContentBuilder(Builder):
  def _key_names(self, delta):
    return ["content", Event.CONTENT_START, Event.CONTENT, Event.CONTENT_END]

class ReasoningBuilder(Builder):
  def _key_names(self, delta):
    return [
      _get_reasoning_field_name(delta),
      Event.REASONING_START,
      Event.REASONING,
      Event.REASONING_END,
    ]

  def is_end(self, chunk: ChatCompletionChunk):
    delta = chunk.choices[0].delta
    return bool(delta.content) or bool(delta.tool_calls) or super().is_end(chunk)

class ToolCallsBuilder(Builder):
  def _key_names(self, delta):
    return [
      "tool_calls",
      Event.TOOL_CALL_START,
      Event.TOOL_CALL,
      Event.TOOL_CALL_END,
    ]

  def emit(self, chunk: ChatCompletionChunk):
    super().emit(chunk)
    if self.value:
      self._normalize_tool_calls()

  def _normalize_tool_calls(self):
    tool_calls = self.value["tool_calls"]  # type: ignore
    for i in range(len(tool_calls)):
      if not isinstance(tool_calls[i], dict):
        tc = tool_calls[i]
        func_obj = getattr(tc, "function", None)
        tool_calls[i] = {
          "id": getattr(tc, "id", None) or "",
          "type": getattr(tc, "type", None) or "function",
          "function": {
            "name": getattr(func_obj, "name", None) or "",
            "arguments": getattr(func_obj, "arguments", None) or "",
          },
        }

  def append_value(self, value, field_name: str):
    tool_calls = self.value[field_name]
    for tc_delta in value:
      idx = tc_delta.index
      while len(tool_calls) <= idx:
        tool_calls.append(
          {
            "id": "",
            "type": "function",
            "function": {"name": "", "arguments": ""},
          }
        )
      tc = tool_calls[idx]
      if delta_id := getattr(tc_delta, "id", None):
        tc["id"] = delta_id
      if delta_type := getattr(tc_delta, "type", None):
        tc["type"] = delta_type
      if delta_func := getattr(tc_delta, "function", None):
        if name := getattr(delta_func, "name", None):
          tc["function"]["name"] = name
        if args := getattr(delta_func, "arguments", None):
          tc["function"]["arguments"] += args

@dataclass
class Model(EventEmitter):
  model_name: str = openai_settings.model
  _client: OpenAI = field(
    default_factory=lambda: OpenAI(
      api_key=openai_settings.api_key,
      base_url=openai_settings.base_url,
    )
  )

  def _invoke(self, session: Session, stream=False):
    "核心方法，调用模型得到结果"
    response = self._client.chat.completions.create(
      model=self.model_name,
      messages=cast(list, session.messages),
      tools=session.tools,
      stream=stream,
    )
    return self._process(session, response)

  def _normalize_result_from_response(self, response: ChatCompletion):
    "将非流式的响应格式进行归一化"
    message = response.choices[0].message
    reasoning_field = _get_reasoning_field_name(message)
    result = InvokeResult(
      raw=response, message={"role": message.role, "content": ""}
    )
    message_dict = message.model_dump()
    for attr_name in [reasoning_field, "content", "tool_calls"]:
      if attr_name in message_dict:
        if message_dict[attr_name]:
          result.message[attr_name] = message_dict[attr_name]
    return result

  def _process(
    self, session: Session, response: ChatCompletion | Stream[ChatCompletionChunk]
  ) -> InvokeResult:
    "处理响应结果"
    if isinstance(response, ChatCompletion):
      result = self._normalize_result_from_response(response)
      session.add_message(result.message)
      return result
    # 处理流式内容
    builders: list[Builder] = [
      ReasoningBuilder(self),
      ContentBuilder(self),
      ToolCallsBuilder(self),
    ]
    chunks = []
    for chunk in response:
      chunks.append(chunk)
      for b in builders:
        b.emit(chunk)
    message = {"role": "assistant", "content": ""}
    for b in builders:
      if b.value:
        for k, v in b.value.items():
          if v is not None:
            message[k] = v
    result = InvokeResult(raw=chunks, message=message)
    session.add_message(result.message)
    return result

  def invoke(self, session: Session):
    return self._invoke(session, stream=False)

  def invoke_stream(self, session: Session):
    return self._invoke(session, stream=True)
```

> **说明：** `_normalize_result_from_response` 会把 `tool_calls` 写进 `result.message`，`_process` 再 `add_message`。不回写的话，本地会话里就只剩一句空 `content`，后面无法执行工具。

## 执行工具

从会话最后一条消息取出 `tool_calls`，解析参数，按名字找到函数并调用。下面用 `# %%` 分段，方便看清每一步；同一套逻辑直接写进 `main.py` 一次跑完也可以。分段用法见 07。

```python

msg

# %%

tool_id = tool_calls["id"]
tool_name = tool_calls["function"]["name"]
arguments = json.loads(tool_calls["function"]["arguments"])

print("tool id", tool_id)
print("tool name", tool_name)

func = globals().get(tool_name)
if callable(func):
  func(**arguments)
```

`write_file` 执行成功后，当前目录会出现 `uv.md`，内容就是模型填进 `content` 的安装教程。

> **说明：** `globals().get(tool_name)` 只在「函数和这段代码处于同一模块」时找得到。`read_file` / `write_file` 必须定义在这个 `main.py` 里，或事先放进该模块的全局命名空间。
>
> 执行完通常还要把结果以 `role: tool`（带上对应 `tool_call_id`）追加进 `session`，再调一次模型，模型才能根据「文件已经写好」继续说话。没有这一步，对话就停在 `finish_reason: tool_calls`。
